# Lista prohibida: apuestas de cualquier tipo

**Regla absoluta.** Ningún texto, metadato, titular, pie, alerta ni etiqueta generado por este sistema trata de apuestas deportivas ni de ningún otro tipo de apuestas o juego de azar. Esto incluye los términos ambiguos: si una palabra puede leerse como apuesta, no se usa.

Aplica a todas las piezas: redacción, radar, auditor SEO, panel, alertas, etiquetas y pies de Instagram.

## Términos prohibidos

No se usan, en ningún sentido, ni dentro de una cita, ni en una frase que hable de decisiones de equipos.

- apuesta, apuestas, apostar, apostado, apuesto, apostamos, apostador, apostadores
- casa de apuestas, casas de apuestas, bookmaker, bookies, bookie, sportsbook
- bet, bets, betting, wager, tipster
- cuota, cuotas, odds, cuota de pago
- parlay, parlé, combinada (en sentido de apuesta), handicap de apuestas, spread (en sentido de apuesta), moneyline, over/under (en sentido de apuesta), línea de apuestas
- juego de azar, casino, ruleta, póker de apuestas, lotería, quiniela, quinielas, boleto de apuestas
- pronóstico con cuota, pronóstico de apuestas, tipo de apuesta
- cualquier enlace, logotipo o mención a operadores de juego

## Alternativas para lo que sí quieres decir

| Si la intención es... | Escribe... |
| --- | --- |
| Una decisión o un fichaje arriesgado | «una decisión», «un movimiento», «un fichaje con riesgo» |
| «Apostar por» un equipo o un jugador | «confiar en», «creer en», «ir a por» |
| «Es una apuesta clara» | «Es una decisión clara» o «Es un movimiento claro» |
| Un pick del Draft | «pick» (solo en el sentido de Draft) |

## Cómo se aplica

- **Redacción:** antes de guardar, se comprueba el texto completo, el titular, el extracto, las etiquetas y el pie de Instagram contra esta lista. Si aparece un término, el borrador no se guarda. Se reescribe el fragmento y se vuelve a comprobar.
- **Radar:** si el título o el resumen de una noticia trata de apuestas, la noticia se descarta y no se crea entrada.
- **Estilo:** los ejemplos de `ESTILO.md` que contengan términos de esta lista no son modelos. No se imitan.
- **Fichas, SEO y alertas:** el mismo filtro antes de escribir.

Cuando dudes, no lo escribas.
