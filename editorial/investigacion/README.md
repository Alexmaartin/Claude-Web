# Investigación para artículos

Dosieres que prepara JalandBot con la red abierta (su entorno no guarda claves). Los usan Redacción, para escribir con su estilo, y el Verificador, para comprobar cada dato.

**Reglas**
- Fuente de partida: Wikipedia (datos factuales; no se copian textos, todo con redacción propia) y la lista de Wikipedia de jugadores undrafted para confirmar quién no fue elegido.
- Basketball-Reference sigue siendo solo para verificar, nunca para redactar. NBA.com bloquea las consultas automáticas.
- Los años que aparecen vacíos o marcados «año por verificar» salen de plantillas de Wikipedia que no se han podido leer: el Verificador los comprueba antes de que pasen al texto. No se rellenan de memoria.
- Los datos son de la Wikipedia en inglés a 21-11-2026. Un dato que no esté en el dosier y que Redacción quiera usar se trata como no comprobado.
- Nada de apuestas ni de metáforas de apuestas.
